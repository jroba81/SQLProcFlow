How to Use

  1. Paste your T-SQL stored procedure code in the left panel
  2. Click "Generate Flowchart" to visualize the procedure
  3. The flowchart will show each step with tables and procedures used
  4. Click "Load Example" to see a sample procedure

Supported Features

  • Statements: SELECT, INSERT, UPDATE, DELETE, EXEC
  • Control Flow: IF/ELSE, WHILE loops, BEGIN/END blocks
  • Detection: Tables, stored procedures, and variables
  • Visualization: Interactive flowcharts with Mermaid.js
